# Autonomous convergence guardrails

Date: 2026-08-29  
Task: `CTL-P1-AUTONOMOUS-CONVERGENCE-GUARDRAILS`

`AGENTS.md` now contains one runner-neutral convergence contract for long
optimization, migration, bootstrap, and task-board sessions.  It requires:

- requested conceptual closure to remain active until every supported hot
  representation is removed or proven cold by inventory, counters, and an
  exact lazy-adapter regression;
- a mandatory end-to-end zoom-out after repeated low-ceiling micro-candidates;
- gates that execute the claimed boundary and reject strict stubs or feature-
  omitting smoke inputs;
- a whole-subsystem same-pattern audit plus a ratchet before repeating an
  expensive gate after an ABI/projection/ownership failure;
- claim-specific acceptance rather than a universal 1.05 threshold;
- counted, owner-specific patches for repeated source shapes;
- phase evidence before calling a regression a correctness cost;
- artifact readback before handoff/existence claims; and
- a fresh contradiction audit before completion, with `DONE_WEAK`, non-empty
  boundaries, and `goal_state.py resume == CONTINUE` remaining unfinished.

The rules are project-generic and name observable checks rather than one
agent, model, transcript, or compiler experiment.
