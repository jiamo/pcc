# Investigation: freestanding Backend 4 relocation selector

## Status

resolved

## Problem Description

Backend 4 copy eligibility, payload copying, and the copy transaction already
had strict freestanding pcc-Python owners, but candidate scoring and page-grouped
selection still lived in managed `py_gc_backend.py`.  That policy combines
fragmentation, remembered pressure, age, large-page deferral, object budgets,
and page handoff.

The finite boundary is candidate scoring plus the public object-budget selector
and the page-budget selector used by `pcc_gc_step`.  Evacuation drain, ZPage
lifecycle, one-epoch forwarding retirement, and the shared write-barrier
dispatcher remain outside this slice.

## Repro

The ownership test failed before implementation because
`freestanding_gc_relocation_selector.py` did not exist (`1 failed in 0.11s`).
The first strict compile then correctly rejected unnamed top-level helpers and
an implicit `ZeroDivisionError` path generated by `% 16`.

## Test [CONFIRMED]

All ten selector functions now have finite ABI names.  The safepoint cadence
uses the equivalent positive-counter check `(selected & 15) == 0`, which avoids
exception machinery in the strict object.  Exact LLVM/self closure, production
archive ownership, the migrated source contract, phase-reset behavior, and
normal pcc-Python step relocation are green.

## Proposals

- No.1 Move page-grouped candidate selection to a strict object [CONFIRMED]

## No.1 Move page-grouped candidate selection to a strict object

### Code Change

Add `freestanding_gc_relocation_selector.py` with two public selectors and
eight finite helper ABIs.  Export only relocation-set insert/find,
evacuation-page insert/find, remembered pressure, object size, config/backend,
graph lock, and safepoint providers.  Remove scoring and selection definitions
from `py_gc_backend.py` and make `pcc_gc_step` consume the strict page selector.

### CONFIRMED

The strict object exports exactly ten definitions and imports only thirteen
declared raw providers plus twelve telemetry/state globals.  The production
archive has one definition per selector symbol, from
`freestanding_gc_relocation_selector.o`.

A fresh self/no-libpython pcc1 was built in 71.551 seconds and compiled the
real strict module in 0.632 seconds.  Clang accepted the IR and no undefined
symbol or call target uses `py_cpy_*`.

## Report

Proposal No.1 landed.  Backend 4 candidate policy and page-grouped selection
are strict freestanding pcc-Python.  Evacuation drain, ZPage lifecycle,
one-epoch forwarding retirement, and shared barrier policy remain explicit
open work; the parent task stays `DONE_WEAK`.
