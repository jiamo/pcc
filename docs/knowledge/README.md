# docs/knowledge — what to read before writing code

This directory holds the decision-shaped facts an agent or a person needs
*before* changing pcc, as opposed to the chronological record of how they were
established (that is `docs/investigations/`, which stays).

Generated by `scripts/distill_investigations.py` from the investigations, and
kept in step by `tests/test_knowledge_pages_are_current.py`:

- [`denied-experiments.md`](denied-experiments.md) — every change somebody
  already wrote, measured and disproved, plus every "did not help" note. **Read
  this first.** Re-deriving one of these costs a full rebuild/measure cycle and
  produces a change known not to work. If your idea is here, either cite new
  evidence that overturns the verdict or do not make the change.
- [`confirmed-root-causes.md`](confirmed-root-causes.md) — mechanisms
  established by an experiment, so a repeat of a known failure is recognised
  instead of re-diagnosed.
- [`symptom-routing.md`](symptom-routing.md) — one line per investigation with
  its status and the error text/symbols it contains. Search it for what you are
  looking at, then read the linked file end to end.

Hand-written pages live here too. They are dated and scoped, never a running
log:

- `2026-09-06-session-handoff.md` — uncommitted state, blockers and decisions
  from the repository split and the raw-pointer typing work.

Regenerate after editing any investigation:

```bash
env -u LC_ALL uv run python scripts/distill_investigations.py
```
